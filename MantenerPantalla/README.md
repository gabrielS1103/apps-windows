Evita que la pantalla se apague o que el equipo se suspenda moviendo el ratón de forma imperceptible.

## Cómo se usa
Ábrelo y queda en la barra de tareas. Clic en el icono para activarlo o desactivarlo, o usa el atajo de teclado (por defecto **Ctrl + Alt + P**). Con doble clic se abre la configuración: cada cuántos segundos mover el ratón, el atajo, si solo debe moverlo cuando no lo estás usando y si debe iniciarse con Windows.

## Compilar
Doble clic en `compilar.bat`: genera `MantenerPantalla.exe` con el `csc.exe` que trae Windows.
